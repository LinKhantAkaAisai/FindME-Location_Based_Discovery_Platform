# Shop Finder App 🏪📱

A modern, social-first platform for discovering shops, sharing community experiences, and managing retail businesses. Built with React Native (Expo) and Node.js.

## 🚀 Quick Start

### Backend
1. **Setup DB**: Create a PostgreSQL database named `findme_local`.
2. **Install**: `cd shop-backend && npm install`
3. **Run**: `node index.js` (Server runs on port 5000)

### Mobile App
1. **Config**: Update `BASE_URL` in `src/services/api.ts` to your local IP.
2. **Install**: `cd mobile && npm install`
3. **Run**: `npx expo start`

## 🌟 Key Social Highlights
- **Unified Comments**: Real-time interaction available on any post.
- **Flexible Profiles**: Hybrid grid/timeline views for user expression.
- **Geo-Discovery**: Integrated map picking and check-in tagging.
- **Shop Hierarchy**: Premium tiers with dedicated dashboards for owners.

## 🛠️ Tech Stack
- **Frontend**: React Native, Expo, React Navigation, Ionicons.
- **Backend**: Express.js, PostgreSQL, Multer (Media), JWT (Auth).
